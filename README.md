# 🛒 Smart Grocery POS

A modern, feature-rich Grocery Point of Sale (POS) application built with Flutter to simplify billing, inventory management, customer records, supplier management, and sales reporting for grocery stores.

Designed with scalability, clean architecture, and an intuitive user experience in mind, Smart Grocery POS helps small and medium-sized businesses manage daily operations efficiently.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/MZahid13/Smart_Grocery_POS.git
```

## Navigate to Project

```bash
cd Smart_Grocery_POS
```

## Install Dependencies

```bash
flutter pub get
```

## Run Application

```bash
flutter run
```
